# Plan 05-01: Streaming Chat API Route & Unit Tests

## Objective
Install the approved client chat and markdown dependencies (`@ai-sdk/react`, `react-markdown` per D-08). Build the conversational chat system prompt builder in `lib/prompts/chat.ts` enforcing strict epistemic non-UPL boundaries, omission reporting, and citation formatting. Implement the Server-Sent Events (SSE) streaming API route at `app/api/chat/route.ts` using Vercel AI SDK `streamText` with Claude 3.5 Sonnet grounded in active document, situation, or comparison context. Author and run comprehensive Vitest tests in `tests/chat-route.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Untrusted Client Ingestion)**: Request payload sent to `/api/chat` contains unauthenticated user messages, context text, and analysis JSON. Attackers could attempt prompt injection, jailbreaking, or payload flooding.
- **TB-02 (External AI Model Boundary)**: Outbound requests to Anthropic Claude 3.5 Sonnet via Vercel AI SDK `streamText`. Model outputs stream directly to the client and must never produce prescriptive legal instructions or hallucinate contract terms.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-05-01** | Information Disclosure / Non-UPL Violation | `lib/prompts/chat.ts` | High | Mitigate | System prompt commands strict non-UPL compliance under Advocates Act, 1961. Explicitly forbids prescriptive second-person counsel ("you should sue", "you must sign", "this is illegal"), enforcing objective informational phrasing ("typical agreements include...", "statutory provisions provide...", "courts generally evaluate...") |
| **T-05-02** | Tampering / Contract Hallucination | `lib/prompts/chat.ts` | High | Mitigate | Enforce strict epistemic omission rule (D-06): when asked about terms or remedies not present in the source text, Claude must explicitly declare `"This document does not address [topic]"` and objectively describe standard practices without fabricating terms |
| **T-05-03** | Denial of Service / Token & Memory Exhaustion | `app/api/chat/route.ts` | Medium | Mitigate | Validate that `messages` is a non-empty array. Truncate `context.text` to 50,000 characters before prompt composition with an explicit truncation notice (D-05) |
| **T-05-04** | Information Disclosure / Stack Trace Leakage | `app/api/chat/route.ts` | Medium | Mitigate | Catch JSON parsing errors and runtime exceptions, returning sanitized structured JSON error envelopes (`CONFIG_ERROR`, `INVALID_REQUEST`, `CHAT_FAILED`) without leaking server stack traces |
</threat_model>

   - Define interface `ChatPromptOptions`:
     ```ts
     export interface ChatPromptOptions {
       mode: 'document' | 'situation' | 'compare';
       sourceText?: string;
       analysisJson?: string;
       documentType?: string;
       parties?: string[];
     }
     ```
   - Implement and export `buildChatSystemPrompt(options: ChatPromptOptions): string`:
     - Embed role: Gavel, an AI legal intelligence assistant providing objective educational information and contract comprehension under the Advocates Act, 1961.
     - Embed mandatory non-UPL directives: NEVER provide prescriptive legal advice or directives like "you should", "you must", or "this is illegal". Enforce objective third-person formulations ("People facing this provision often...", "Statutory provisions such as...", "Courts have generally held...", "It is advisable to discuss with licensed counsel...").
     - Embed strict epistemic omission directive (D-06): If the user asks about a clause, provision, right, or topic that is not addressed in the source document or situation text, Claude MUST explicitly state: `"This document does not address [topic]."` followed by what is standard and a recommendation to ask legal counsel.
     - Embed citation syntax directive (D-07): Direct Claude to cite exact clauses, provisions, or sections using bracketed format: `[Clause X: Title]` or `[Section Y]` so the UI can render them as distinct gold monospace badges.
     - Embed concise response formatting guidelines: 2 to 4 focused paragraphs or clear bullet lists.
     - Embed active context blocks: Mode identifier (`DOCUMENT`, `SITUATION`, or `COMPARISON`), Document Classification/Parties (if present), Source Text (enclosed in `<source_text>` tags), and Prior Structured Analysis (enclosed in `<prior_analysis>` tags).
  </action>

  <action>
1. Create `app/api/chat/route.ts`:
   - Set Next.js route configurations:
     ```ts
     export const runtime = 'nodejs';
     export const dynamic = 'force-dynamic';
     export const maxDuration = 60;
     ```
   - Import `streamText`, `convertToModelMessages`, `type UIMessage` from `ai`.
   - Import `anthropic` from `@ai-sdk/anthropic`.
   - Import `buildChatSystemPrompt` from `@/lib/prompts/chat`.
   - Implement `POST(req: NextRequest)`:
     - Check `process.env.ANTHROPIC_API_KEY`. If missing, return 500 with `{ error: 'CONFIG_ERROR', message: 'Anthropic API key is not configured.' }`.
     - Parse JSON body safely. On error, return 400 with `{ error: 'INVALID_REQUEST', message: 'Malformed JSON payload.' }`.
     - Validate `messages`: check that `Array.isArray(messages)` and `messages.length > 0`. If invalid, return 400 with `{ error: 'INVALID_REQUEST', message: 'Messages array is required.' }`.
     - Extract `context` payload:
       - `mode`: `'document' | 'situation' | 'compare'` (default `'document'`).
       - `text`: truncate string to 50,000 characters if length exceeds 50,000, appending `'\n\n[...Source text truncated to 50,000 characters]'` (D-05).
       - `analysis`: stringify to JSON if provided.
       - `documentType`: string optional.
       - `parties`: string array optional.
     - Convert UI messages using `await convertToModelMessages(messages)`.
     - Build system prompt via `buildChatSystemPrompt(...)`.
     - Call `streamText({ model: anthropic('claude-3-5-sonnet-20241022'), system, messages: modelMessages })`.
     - Return `result.toUIMessageStreamResponse()`.
     - Wrap in try/catch returning 500 `{ error: 'CHAT_FAILED', message: error instanceof Error ? error.message : 'Chat streaming failed.' }`.
  </action>

    - Returns 500 `CONFIG_ERROR` if `ANTHROPIC_API_KEY` is not present.
    - Returns 400 `INVALID_REQUEST` if body is malformed or messages is not a non-empty array.
    - Truncates oversized source text at 50,000 characters.
    - Invokes `streamText` with `claude-3-5-sonnet-20241022` and returns `toUIMessageStreamResponse()`.

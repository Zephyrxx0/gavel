# Plan 05-02: Universal Export Engines, Dossier Card & Formatters

## Objective
Implement universal client-side dossier export engines in `lib/export-utils.ts` to convert active analysis reports (Document Decoder, Situation Navigator, and Document Comparison) into formatted Markdown (`.md`), clean ASCII Plain Text (`.txt`), and structured JSON (`.json`) with mandatory statutory legal disclaimers. Implement the in-browser ephemeral download engine and clipboard copy utilities with Sonner toast feedback. Build the reusable `ExportDossierCard.tsx` presentation component for report footers. Author and verify comprehensive unit tests in `tests/export-utils.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Client Data Serialization Boundary)**: Analysis data stored in client React state is serialized into file streams and clipboard text. Must preserve data integrity and prevent injection of malicious code or file system traversal.
- **TB-02 (Compliance & Regulatory Boundary)**: Exported legal documents may be shared or presented outside the application context. Failure to include prominent statutory disclaimers creates severe regulatory liability under the Advocates Act, 1961.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-05-05** | Repudiation / Non-Compliance | `lib/export-utils.ts` | High | Mitigate | Every export formatter (Markdown and Plain Text) unconditionally prepends an unalterable statutory legal disclaimer block citing the Advocates Act, 1961 and explicitly confirming that Gavel is not a law firm (D-11, CORE-02) |
| **T-05-06** | Information Disclosure / Data Persistence Violation | `lib/export-utils.ts` | High | Mitigate | All file downloads are constructed in browser memory using `new Blob([...])` and `URL.createObjectURL(blob)`, revoked immediately after programmatic click. Zero data is sent to backend endpoints or persisted on disk (CORE-04) |
| **T-05-07** | Tampering / Filename Path Traversal | `lib/export-utils.ts` | Medium | Mitigate | Sanitize suggested download filenames by replacing path separators (`/`, `\`), null bytes, and non-alphanumeric characters (except dashes and underscores) before anchor generation |
</threat_model>

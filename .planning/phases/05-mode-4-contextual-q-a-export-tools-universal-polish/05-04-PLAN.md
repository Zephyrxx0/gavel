# Plan 05-04: StickyNav Upgrades, Mode Integration, Mobile Polish & Verification Gate

## Objective
Upgrade the sticky navigation headers across all three modes (Mode 1 Decoder, Mode 2 Navigator, Mode 3 Comparison) with "Ask Gavel" triggers, export dropdown actions, and touch-hardened horizontal anchor rails. Add responsive mobile/tablet top navigation parity to Comparison mode. Integrate `ChatPanel`, `ChatTriggerButton`, and `ExportDossierCard` into the three analysis page controllers (`app/analyze/document/page.tsx`, `app/analyze/situation/page.tsx`, `app/analyze/compare/page.tsx`). Audit end-to-end mobile responsiveness, safe area insets, and disclaimer presence. Execute the full verification gate (`npm test -- --run` and `npm run build`).

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Cross-Mode State Boundary)**: Context payload passed to `ChatPanel` and `ExportDossierCard` must match the active analysis state precisely. Passing stale or mismatched analysis data could corrupt export files or misguide AI streaming chat.
- **TB-02 (Mobile Interaction & Usability Boundary)**: Mobile users with small screens, virtual keyboards, or touch gestures must retain complete access to legal disclaimers, chat controls, and export tools without UI clipping or overlap.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-05-11** | Information Disclosure / Context Desynchronization | Page Controllers (`app/analyze/*/page.tsx`) | Medium | Mitigate | Only pass non-null, validated `analysisData` and source text to `ChatPanel` and `ExportDossierCard` when in `'dossier'` state. Reset chat and export contexts whenever the user resets or starts a new analysis |
| **T-05-12** | Usability / Touch Accessibility Violation | StickyNavs & Trigger Buttons | Low | Mitigate | Enforce minimum 44x44px touch targets on all buttons and anchor chips. Add iOS `env(safe-area-inset-bottom)` padding to prevent mobile system navigation bar occlusion (D-15) |
</threat_model>

# Plan 02-04: Full Page Integration, Sticky Nav & Loading/Error States

## Objective
Unify the Document Decoder pipeline into an end-to-end user experience at `/analyze/document`. Implement the docked `StickyNav` with scroll-spy and badge counts, `AnalysisProgress` multi-stage animated loader with elapsed timer, and `AnalysisErrorCard` with retry controls. Build the dedicated page orchestrator `app/analyze/document/page.tsx` seamlessly transitioning between intake, progress, and the 4-layer legal dossier with ephemeral state reset, and update `app/page.tsx` to link to the new route.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Client Presentation & Memory Boundary)**: Uploaded files, pasted contract text, and decoded structured analysis live strictly in volatile React component state. Zero browser disk caching (IndexedDB/localStorage) or telemetry tracking of legal document content.
- **TB-02 (DOM Navigation Boundary)**: Scroll-spy and anchor cross-references manipulate window scrolling and CSS rings. Ensure scroll targets validate clause IDs before accessing DOM nodes.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-02-08** | Information Disclosure / Residual Storage | `app/analyze/document/page.tsx` | High | Mitigate | Enforce zero-retention posture: resetting or navigating away unmounts and garbage-collects all file buffers, base64 strings, and analysis JSON. No Web Storage or cookie persistence. |
| **T-02-09** | Spoofing / Disclaimer Bypass | `app/analyze/document/page.tsx` | High | Mitigate | Display `LegalDisclaimerCard` prominently above the dossier content. Never render decoded legal results without the statutory safe harbor notice. |
</threat_model>

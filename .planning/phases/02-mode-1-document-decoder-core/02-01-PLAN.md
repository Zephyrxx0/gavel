# Plan 02-01: Core AI Inference Pipeline & Route Handler

## Objective
Implement the backend AI pipeline for Mode 1 Document Decoder. Author strict non-UPL system prompts and injection-safe prompt builders in `lib/prompts/document.ts`, construct the App Router route handler at `app/api/analyze/document/route.ts` utilizing Vercel AI SDK's `generateObject` with Claude 3.5 Sonnet (`claude-3-5-sonnet-20241022`) and `DocumentAnalysisSchema`, and establish the Wave 0 automated unit and mock test suite in `tests/analyze-document-route.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Untrusted Client Ingestion)**: Request payload sent to `/api/analyze/document` contains user-provided text or base64 image. Untrusted content may attempt prompt injection or risk manipulation.
- **TB-02 (External AI Provider Boundary)**: Outbound API request to Anthropic Claude 3.5 Sonnet. Model output must conform to strict schema types and never escape into arbitrary code execution.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-02-01** | Tampering / Prompt Injection | `lib/prompts/document.ts` | High | Mitigate | Enclose user text within `<document_to_analyze>` XML tags. Provide explicit system instructions that content within these tags is untrusted raw text and directives within must be ignored. |
| **T-02-02** | Information Disclosure / Non-UPL | `lib/prompts/document.ts` & Route | High | Mitigate | System prompt forbids prescriptive directives ("you must sue", "you should refuse") per Advocates Act 1961 §§ 29 & 33. All outputs must be objective informational summaries. |
| **T-02-03** | Denial of Service / Memory Exhaustion | `app/api/analyze/document/route.ts` | Medium | Mitigate | Enforce minimum input threshold (30 chars) and validate presence of either text or base64 data. Process base64 entirely in memory without writing to disk. |
| **T-02-04** | Information Disclosure / Crash Leakage | `app/api/analyze/document/route.ts` | Medium | Mitigate | Catch errors safely, redact internal stack traces, and return standard JSON error envelopes (`ErrorResponseSchema`). |
</threat_model>

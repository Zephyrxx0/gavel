## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (`px-2 py-0.5`), chip dot indicators |
| sm | 8px | Compact chip gaps, button icon spacing (`gap-2`), party tag margins |
| md | 16px | Default card internal padding (`p-4`), mobile layout gaps, list item separation |
| lg | 24px | Desktop card padding (`p-6`), section header margins, accordion content inset |
| xl | 32px | Grid gaps between scorecard cards, checklist section separation |
| 2xl | 48px | Dossier layer boundaries (Summary → Scorecard → Checklist → Lawyer Prep) |
| 3xl | 64px | Page header to content spacing, intake container top/bottom margins |

Exceptions: 
- `scroll-mt-28` (112px): Fixed header + sticky anchor navigation offset compensation applied to all anchored sections (`#summary-section`, `#risks-section`, `#checklist-section`, `#lawyer-prep-section`, `#clause-[id]`).
- `max-h-80` (320px) / `max-h-96` (384px): Max height constraint for scrollable verbatim original legal text blocks.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B0F17` (`legal-obsidian`) | Page background, backdrop overlays, sticky nav dock background |
| Secondary (30%) | `#111827` (`legal-card`), `#0F172A` (`card-subtle`), `#1E293B` (`legal-slate`) | Card surfaces, container panels, borders, divider separators, hover states |
| Accent (10%) | `#D4AF37` (`legal-gold`) / `#C5A059` (`gold-muted`) | Specific high-leverage highlights only (see explicit reservation list below) |
| Destructive | `#EF4444` (`risk-high`) | High-risk clause left-border accent, "Refuse" action badge, fatal error card headers |

Accent reserved for:
1. Primary CTA interactive states ("Analyze Legal Document", "Analyze Another Document")
2. Active scroll-spy tab indicator border and text in `StickyNav`
3. Momentary cross-reference clause pulse target (`ring-2 ring-[#D4AF37] bg-[#D4AF37]/10`)
4. Executive Summary golden accent frame border (`border-[#D4AF37]/30`)
5. Elapsed timer digit callout during analysis progress (`text-[#D4AF37]`)
6. Statutory safe-harbor badge icon accents (`LegalDisclaimerCard`)

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Risk Scorecard (`RiskScorecard.tsx`) | ✅ covered | When a filter chip yields 0 items, renders documented empty state: "No clauses match the selected risk tier." with a button to reset filter to 'All Clauses'. |
| empty | Action Checklist categories (`ActionChecklist.tsx`) | ✅ covered | If an operational group (`Immediate`, `Before Signing`, or `After Signing`) contains 0 items, renders subtle empty state container with verified checkmark and "No {timing} action items identified". |
| empty | Party Extraction (`ExecutiveSummaryCard.tsx`) | ✅ covered | When `parties` array is empty, renders "Signatory entities not explicitly declared in source text" in muted mono italics instead of a blank card area. |
| loading | Document Ingestion & Route Handler (`AnalysisProgress.tsx`) | ✅ covered | Animated milestone ticker cycling through stages 1, 2, and 3 with real-time second counter, pulsing gold halo indicator, and zero-retention privacy badge. |
| error | AI Endpoint & Network Failures (`AnalysisErrorCard.tsx`) | ✅ covered | Replaces loader on 4xx/5xx/timeout with high-contrast diagnostic error card containing plain-English error cause, "Retry Analysis" CTA, and "Adjust Input Text" fallback to intake. |
| populated | Complete Document Dossier (`app/analyze/document/page.tsx`) | ✅ covered | Renders StickyNav docked below Header, LegalDisclaimerCard, ExecutiveSummaryCard, RiskScorecard, ActionChecklist, and LawyerPrepGuide in a continuous single-scroll dossier. |
| overflow | Verbatim Legal Excerpt (`ClauseCard.tsx`) | ✅ covered | Radix Accordion wraps verbatim original legal text inside a scrollable container (`max-h-80 overflow-y-auto`) with monospace formatting and custom slate scrollbars to prevent vertical viewport blowouts. |
| overflow | Sticky Navigation Bar (`StickyNav.tsx`) | ✅ covered | On mobile viewports (`< 768px`), the navigation pills enable horizontal kinetic touch scrolling (`overflow-x-auto no-scrollbar flex-nowrap`) so all 4 sections and counter badges remain accessible. |

## Registry Safety

### Components Needed for Phase 2

1. **`checkbox`** (Radix UI `@radix-ui/react-checkbox`):
   - Needed for `ActionChecklist.tsx` interactive check-off states (Decision D-09).
   - Will install via shadcn CLI or provide local wrapper in `components/ui/checkbox.tsx`.
2. **`card`** (Standard shadcn layout primitive):
   - Provides consistent slate borders (`border-slate-800`), background (`bg-[#111827]`), and padding structure (`CardHeader`, `CardTitle`, `CardContent`).
3. **`separator`** (Radix UI `@radix-ui/react-separator`):
   - Crisp 1px hairline divider (`bg-slate-800`) separating clauses, timing groups, and party tags.
4. **`scroll-area`** (Radix UI `@radix-ui/react-scroll-area`):
   - Headless custom scrollbars for long legal source text blocks inside accordions.

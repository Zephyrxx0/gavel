# Plan 03-02: Dispute Intake Experience & 3-Stage Progress Loader

## Objective
Build the conversational dispute intake interface for Mode 2 at `/analyze/situation`. Implement 4 clickable quick-start preset cards (D-01), category pre-filter chips with Lucide icons (D-13), the main narrative textarea with live word count validation and guided contextual prompt helpers for inputs under 20 words (SIT-01, D-02), and SSR-safe `sessionStorage` draft persistence (D-04). Construct the 3-stage animated progress loader with live elapsed second timer and privacy notice (D-15), with incremental automated component tests in `tests/situation-intake.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Client Web Storage Boundary)**: Saving in-progress dispute narratives in the user's browser. Draft facts may contain sensitive personal or commercial details.
- **TB-02 (DOM Rendering & Contextual Guidance Boundary)**: Rendering user input and preset strings in the DOM. Must prevent DOM injection and avoid prescriptive legal determinations in prompt helpers.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-03-05** | Information Disclosure / Persistent Data Remanence | `SituationIntakeForm.tsx` | High | Mitigate | Confine draft storage strictly to browser `sessionStorage` (`gavel_situation_draft_v1`), never `localStorage`, cookies, or remote databases. Draft is tab-scoped, cleared on "Clear Draft" and on starting a new situation, and destroyed when the tab closes. |
| **T-03-06** | Information Disclosure / Non-UPL Violation | `SituationIntakeForm.tsx` (Prompt Helpers) | Medium | Mitigate | Contextual helper banner must prompt only for objective factual elements ("Who was involved? What was promised? Roughly when?") without framing claims, assigning liability, or offering legal theories. |
| **T-03-07** | Client Denial of Service / SSR Hydration Desync | `SituationIntakeForm.tsx` & `SituationProgress.tsx` | Low | Mitigate | Access `sessionStorage` and `window` only inside `useEffect` or after a mounted check (`typeof window !== 'undefined'`) to avoid hydration errors or server-side execution crashes. |
</threat_model>

1. Create `components/situation/SituationIntakeForm.tsx`:
   - Accept props: `onSubmit: (description: string, category?: DisputeCategory) => void`, `isLoading?: boolean`.
   - Manage state: `description: string`, `category: CategoryFilterValue`, `mounted: boolean`.
   - `useEffect` on mount restores draft from `sessionStorage.getItem('gavel_situation_draft_v1')`.
   - On textarea input change, update state and write to `sessionStorage.setItem('gavel_situation_draft_v1', val)`.
   - Calculate live word count: `countWords = (s: string) => (s.trim() ? s.trim().split(/\s+/).filter(Boolean).length : 0)`.
   - Render word count badge:
     - If `< 20`: `"{count} / 20 words minimum"` in muted slate styling.
     - If `>= 20`: `"{count} words"` in emerald styling (`text-emerald-400 bg-emerald-950/40 border-emerald-500/30`).
   - If `mounted && countWords > 0 && countWords < 20`, render the inline prompt helper banner per D-02 and UI-SPEC:
     - Heading: `"Could you add a bit more detail? For the most accurate legal rights breakdown, consider: Who was involved? What was promised or agreed? Roughly when did this happen?"`
     - Bullets: Who was involved? What was promised or agreed? Roughly when did this happen?
   - "Clear Draft" button (`RotateCcw` icon) clears textarea, resets category to `'auto'`, and calls `sessionStorage.removeItem('gavel_situation_draft_v1')`.
   - Primary submit button:
     - If `< 20` words: disabled, label `"Analyze Situation (Minimum 20 Words Required)"`.
     - If `>= 20` words: enabled, label `"Analyze Situation"`, gold styling (`bg-[#D4AF37] hover:bg-[#C5A059] text-black font-semibold`).
   - On submit, call `onSubmit(description.trim(), category !== 'auto' ? category : undefined)`.

## Must-Haves (Goal-Backward Verification)

### Observable Truths
- Entering dispute text updates the live word counter dynamically.
- Inputting fewer than 20 words disables the submit button and renders the contextual guided prompt banner.
- Inputting 20 or more words enables the "Analyze Situation" submit button with legal gold styling.
- Clicking any of the 4 quick-start preset cards instantly populates the textarea with a detailed scenario (60–80 words) and selects the matching category chip.
- Typed draft text persists across accidental browser refreshes via `sessionStorage` and clears when "Clear Draft" is clicked.
- `SituationProgress` displays an animated timer and transitions through all 3 evaluation milestone stages.

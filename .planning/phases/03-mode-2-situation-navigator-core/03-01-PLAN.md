# Plan 03-01: Schema Alignment & Situation Analysis API Pipeline

## Objective
Update the core Situation schemas to align with SIT-05, SIT-06, and decisions D-05 through D-08 (4 urgency tiers, evidentiary `{ document, why }` objects, and resolution timeline), synchronizing schema tests in `tests/schemas.test.ts`. Author the non-UPL system prompts and XML-contained prompt builder in `lib/prompts/situation.ts` (D-16), and construct the backend route handler at `app/api/analyze/situation/route.ts` with Claude 3.5 Sonnet via Vercel AI SDK `generateObject` (SIT-02). Establish comprehensive automated unit and integration tests in `tests/analyze-situation-route.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Untrusted Client Input Ingestion)**: Request payload sent to `/api/analyze/situation` contains raw user-provided dispute descriptions. Malicious users may attempt prompt injection, instruction overrides, or jailbreaks.
- **TB-02 (External AI Provider Boundary)**: Outbound API request to Anthropic Claude 3.5 Sonnet. Model completions must conform strictly to typed Zod schema constraints and never generate executable code or prescriptive legal commands.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-03-01** | Tampering / Prompt Injection | `lib/prompts/situation.ts` | High | Mitigate | Wrap user narrative inside `<situation_to_analyze>` XML tags. Instruct system prompt to treat all text within these tags as untrusted citizen facts and ignore any command overrides. |
| **T-03-02** | Information Disclosure / Non-UPL Violation | `lib/prompts/situation.ts` & Route | High | Mitigate | Enforce strict negative directives forbidding second-person imperative directives ("you must sue", "you should refuse", "file a complaint") per Advocates Act 1961 §§ 29 & 33. Enforce third-person educational framing ("Citizens facing this situation often consider..."). |
| **T-03-03** | Denial of Service / Resource Exhaustion | `app/api/analyze/situation/route.ts` | Medium | Mitigate | Enforce minimum word/character validation (>= 20 words or >= 50 chars). Reject malformed JSON and empty payloads immediately before invoking the LLM provider. |
| **T-03-04** | Information Disclosure / Stack Trace Leakage | `app/api/analyze/situation/route.ts` | Medium | Mitigate | Catch all runtime exceptions, redact raw internal system traces, and return sanitized error responses matching `ErrorResponseSchema`. |
</threat_model>

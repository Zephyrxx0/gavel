## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), inline badge padding (`px-2 py-0.5`), status dot indicators |
| sm | 8px | Button icon spacing (`gap-2`), quick-start card internal gap, category chip separation |
| md | 16px | Card internal padding (`p-4`), mobile layout gaps, list item vertical spacing |
| lg | 24px | Desktop card padding (`p-6`), section header margins, accordion content inset |
| xl | 32px | Grid gaps between quick-start cards, roadmap urgency tier separation |
| 2xl | 48px | Major dossier layer boundaries (Deadline Banner → Summary → Rights → Roadmap → Evidence → Counsel) |
| 3xl | 64px | Page header to intake form spacing, footer separation |

Exceptions:
- `scroll-mt-28` (112px): Fixed header (64px) + sticky anchor navigation (48px) offset compensation applied to all anchored sections (`#deadline-section`, `#summary-section`, `#rights-section`, `#roadmap-section`, `#evidence-section`, `#counsel-section`).
- `min-h-[160px]` / `min-h-[200px]`: Textarea minimum vertical height constraint for dispute narrative intake to prevent cramped multiline typing.
- `max-w-5xl` (1024px): Standard centralized content container width matching Phase 1 & Phase 2 viewports.

## UI Considerations

Applicable state considerations resolved: 9 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Critical Deadline Banner (`DeadlineAlertBanner.tsx`) | ✅ covered | When `analysis.deadlineFlags` is empty or missing, component returns `null` and omits the top alert banner entirely without reserving blank DOM space. |
| empty | Evidence Checklist (`EvidenceChecklist.tsx`) | ✅ covered | When `documentsToGather` is empty, renders subtle container with checkmark icon and documented copy: "No mandatory evidentiary documents identified for this dispute." |
| empty | Roadmap Urgency Group (`NextStepsRoadmap.tsx`) | ✅ covered | If a specific urgency tier (e.g. `immediate`) has 0 items, that specific tier group is omitted or collapsed, keeping only populated tiers rendered. |
| long-text | Dispute Narrative Textarea (`SituationIntakeForm.tsx`) | ✅ covered | Supports unlimited paste with kinetic auto-scroll, `min-h-[160px]`, and live word counting regex `text.trim().split(/\s+/).filter(Boolean).length` that ignores whitespace padding. |
| long-text | Statutory Right Body & Citation (`RightsAccordion.tsx`) | ✅ covered | Long statutory explanations render inside flexible text containers with `leading-relaxed` typography; statute citations use `whitespace-nowrap font-mono` badges with text truncation fallback if exceeding card width. |
| loading | Ingestion & LLM Evaluation (`SituationProgress.tsx`) | ✅ covered | 3-stage animated progress card cycling at 0s, 4s, and 8s intervals with live elapsed second timer, gold pulsing halo, and zero-retention privacy badge. |
| error | AI Endpoint & Validation Failures (`SituationErrorCard.tsx`) | ✅ covered | Renders high-contrast red-tinted diagnostic card with explicit error cause, "Retry Analysis" button (re-submits identical payload), and "Adjust Dispute Description" button (returns to intake with draft preserved). |
| populated | Complete Situation Dossier (`app/analyze/situation/page.tsx`) | ✅ covered | Integrates StickyNav, DeadlineAlertBanner, SituationSummaryCard, RightsAccordion, NextStepsRoadmap, EvidenceChecklist, and CounselTriggersCard in continuous single-scroll layout. |
| overflow | Sticky Navigation Bar (`SituationStickyNav.tsx`) | ✅ covered | On mobile screens (`< 768px`), navigation buttons enable kinetic horizontal touch scrolling (`overflow-x-auto no-scrollbar flex-nowrap`) to preserve access to all 5 section anchors and counter badges. |

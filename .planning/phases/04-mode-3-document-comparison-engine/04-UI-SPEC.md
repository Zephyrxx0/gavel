## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, badge internal padding |
| sm | 8px (`gap-2`, `p-2`) | Compact element spacing, chip inner padding |
| md | 16px (`gap-4`, `p-4`) | Default element spacing, card sections |
| lg | 24px (`gap-6`, `p-6`) | Card padding, section gutters |
| xl | 32px (`gap-8`, `p-8`) | Layout section spacing |
| 2xl | 48px (`space-y-12`) | Major section breaks in dossier |
| 3xl | 64px | Page-level top/bottom padding |

**Exceptions:**
- Touch targets for filter chips and nav pill buttons: minimum `h-8 px-3` (32px height) for mobile tap comfort
- Sticky nav height: `h-12` (48px) — matches `SituationStickyNav.tsx` pattern exactly
- Progress card: `p-8 max-w-xl mx-auto` — matches `SituationProgress.tsx` pattern
- Clause text area: `p-3` (`12px`) internal — denser for verbatim mono text blocks
- Negotiation card checkboxes: `p-3.5` inner padding for touch comfort

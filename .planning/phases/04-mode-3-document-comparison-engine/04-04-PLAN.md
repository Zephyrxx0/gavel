# Plan 04-04: Page Controller Orchestration & Homepage Integration

## Objective
Assemble the complete end-to-end user experience for Mode 3 Document Comparison Engine at `/analyze/compare`. Implement `ComparisonErrorCard` with comparison-specific retry and document adjustment controls. Author the page controller `app/analyze/compare/page.tsx` coordinating the 4-state lifecycle (`idle`, `analyzing`, `dossier`, `error`), API invocation, scroll-spy navigation, and large-document feedback. Update the homepage (`app/page.tsx`) to integrate the Mode 3 discovery card into a side-by-side grid with Mode 2. Verify complete test coverage and successful production build.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Ephemeral Client State Boundary)**: User documents, analysis payloads, and dossier results exist strictly in volatile React component state. Zero persistence to browser storage, cookies, or remote databases.
- **TB-02 (Statutory Disclaimer Boundary)**: All comparison analysis must be rendered alongside non-dismissible statutory disclaimers to prevent user reliance on AI analysis as formal attorney representation.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-04-11** | Information Disclosure / Residual Data Remanence | `app/analyze/compare/page.tsx` | High | Mitigate | Enforce zero-retention posture: resetting or navigating away unmounts state and purges all document strings. No browser storage (`localStorage` / `sessionStorage`) is used for document comparison. |
| **T-04-12** | Spoofing / Disclaimer Absence | `app/analyze/compare/page.tsx` | High | Mitigate | Mount `<LegalDisclaimer />` prominently at top and bottom of the compare page. It cannot be closed or hidden. |
| **T-04-13** | Denial of Service / State Desync on Retry | `app/analyze/compare/page.tsx` | Medium | Mitigate | Maintain immutable request payloads during retries, guarding against race conditions or orphaned loading screens. |
</threat_model>

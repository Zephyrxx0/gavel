# Plan 04-03: Comparison Dossier Presentation Components

## Objective
Implement the 4 core presentation layers and sticky navigation bar for the Mode 3 Comparison Dossier at `/analyze/compare`. Build the hero `FavorabilityVerdictCard` with verdict pills and favorability metric counters (COMP-03, D-08, D-16), the responsive side-by-side `ClauseComparisonTable` formatted in JetBrains Mono with risk sorting and category filter chips (COMP-04, D-05, D-06, D-07), the severity-badged `InconsistenciesSection` (COMP-05, D-14), the 3-bucket actionable `NegotiationGuide` with clipboard actions (COMP-06, D-13), and the docked `ComparisonStickyNav` (D-09). Validate all presentation components with automated Vitest tests in `tests/comparison-components.test.ts`.

<threat_model>
### ASVS L1 Threat Assessment

#### Trust Boundaries
- **TB-01 (Client DOM Presentation Layer)**: Displaying verbatim excerpts from two legal agreements and AI-generated comparative analysis in the DOM. Ensure all plain-English legal explanations remain educational without prescriptive legal advice.
- **TB-02 (DOM Rendering & XSS Prevention)**: AI analysis strings and verbatim contract provisions must be rendered safely as text nodes without executing embedded HTML or script injections.

#### STRIDE Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| **T-04-08** | Tampering / Cross-Site Scripting (XSS) | `ClauseComparisonTable.tsx` & Dossier | High | Mitigate | Render all verbatim contract excerpts and AI commentary as standard React text nodes (`children`), never using `dangerouslySetInnerHTML`. |
| **T-04-09** | Information Disclosure / Non-UPL Violation | `FavorabilityVerdictCard.tsx` & `NegotiationGuide.tsx` | High | Mitigate | Clearly frame all recommendations as objective commercial options rather than prescriptive legal strategy ("Clauses in this category often warrant counter-proposals in standard commercial negotiations"). Display non-UPL notice. |
| **T-04-10** | Client Memory Leak / Volatile Storage | `NegotiationGuide.tsx` | Low | Mitigate | Manage interactive checkbox states in local React state keyed by item id/title. Never persist state to cookies or external storage. |
</threat_model>
